# xihe-runtime

Xihe Runtime — Rust-based Agent container runtime responsible for MCP Server lifecycle management and tool routing.

## Tech Stack

- **Rust** + **Axum** — HTTP service
- **Cargo** — Build tool

## Development

```bash
cargo build           # Build
cargo test            # Run tests
cargo clippy          # Lint
```
