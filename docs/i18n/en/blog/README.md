# Engineering Blog

Narrative posts: why a design looks the way it does, which traps were hit, what trade-offs were made.
This is a different genre from `DEV-0xx` (a reference manual). File names use `YYYY-MM-DD-<slug>.md`
and do not consume `DEV` numbering.

The Chinese edition is the source of truth: `docs/i18n/zh-Hans/blog/`.
