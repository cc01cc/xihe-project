# xihe-ui

羲和前端界面 — 基于 Vue 3 的 Agent 运行时管理 UI。

## 技术栈

- **Vue 3** + Composition API
- **Vite** — 构建工具
- **shadcn-vue** — UI 组件库
- **Tailwind CSS** — 样式

## 开发

```bash
pnpm dev     # 启动开发服务器
pnpm build   # 构建生产版本
pnpm lint    # 代码检查
```
