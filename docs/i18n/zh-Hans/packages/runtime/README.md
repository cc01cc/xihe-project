# xihe-runtime

羲和运行时 — 基于 Rust 的 Agent 容器运行时，负责 MCP Server 生命周期管理和工具路由。

## 技术栈

- **Rust** + **Axum** — HTTP 服务
- **Cargo** — 构建工具

## 开发

```bash
cargo build           # 构建
cargo test            # 运行测试
cargo clippy          # lint
```
