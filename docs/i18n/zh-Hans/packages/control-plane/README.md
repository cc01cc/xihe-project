# xihe-control-plane

羲和控制平面 — 基于 Spring Boot 的管理服务，负责配置管理、用户认证和 Agent 编排。

## 技术栈

- **Java 25** + **Spring Boot 4.x**
- **PostgreSQL** — 数据存储
- **Maven** — 构建工具

## 开发

```bash
./mvnw spring-boot:run    # 启动开发服务器
./mvnw test               # 运行测试
```
